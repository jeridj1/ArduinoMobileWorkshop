# Third-party software

## Arduino CLI for Android

The Android APK build includes an Android/ARM64 build of Arduino CLI produced from the `ipodvideo87/arduino-cli-android` project. That project is a GPL-3.0-licensed fork of Arduino CLI and is built by the GitHub Actions workflow at build time.

Source: https://github.com/ipodvideo87/arduino-cli-android

Arduino CLI is GPL-3.0 licensed. Its source and license are available from the upstream Arduino CLI project:
https://github.com/arduino/arduino-cli

The USB serial dependency is `com.github.mik3y:usb-serial-for-android`.
